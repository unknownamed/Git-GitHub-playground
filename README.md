# Git & GitHub Playground

**텍스트 파일을 수정하며 Git과 GitHub의 기본 작업을 연습한 개인 실습 저장소입니다.**

## 저장소 구성

| 파일 | 역할 |
| --- | --- |
| [content.txt](content.txt) | 파일 변경 실습용 텍스트 |
| [test.txt](test.txt) | 추가 변경 실습용 텍스트 |

이 저장소에는 실행 프로그램이 없습니다. 파일 변경과 커밋 기록을 살펴보는 연습용 자료입니다.

## 확인 방법

```bash
git clone https://github.com/unknownamed/Git-GitHub-playground.git
cd Git-GitHub-playground
git log --oneline --graph --all
git show <커밋ID>
```
